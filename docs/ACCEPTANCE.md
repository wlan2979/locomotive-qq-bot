# 全新环境验收清单

用于回答一个问题：**别人拿到这个包，能不能装上并跑起来。**

八条全过才算通过。当前状态见 README 的「当前状态」表。

## 准备

- 一台干净的 Windows 10 22H2 或 Windows 11 虚拟机
- **不要**预装 Python、不要预装 WebView2 运行时
- 一个已登录的 OneBot 11 兼容协议端（可以和被测机器同一台，也可以局域网另一台）
- 一个模型 API Key

## 检查项

| # | 动作 | 期望结果 |
|---|---|---|
| 1 | 干净机器（无 WebView2）双击 `Locomotive.exe` | 弹原生中文框提示安装 WebView2，随后退出；**不出现白屏或静默闪退** |
| 2 | 装 WebView2 后启动 | 出现 1100×850 窗口，侧栏底部版本号正确 |
| 3 | 再双击一次 exe（同一数据目录） | 不开第二个窗口，已有窗口被拉到前台 |
| 4 | 用不同 `--data-dir` 再启动一个 | **可以**开第二个窗口（v4.1.3 起支持） |
| 5 | 协议端开启正向 WebSocket（`array` + token） | 端口处于 LISTENING |
| 6 | 工作台填入 `ws://127.0.0.1:3001` + token → 连接 | 状态变「已连接」 |
| 7 | 私聊发一句 / 群里 @ 一句 | 均有回复，`data/history.json` 有记录 |
| 8 | 关闭协议端，等约 5 分钟 | 日志出现 ERROR 级提示并说明处置办法（不是无声沉默） |
| 9 | 重新启动协议端 | 机器人自动重连，无需重启程序 |

第 1、3、4、8、9 条覆盖的是 v4.1.1 之后新写的代码，此前只在开发机上自测过。

## 从源码再走一遍

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
cd src
python app.py
```

如果 `pip install` 有解析冲突或缺失，请把完整的报错贴进 Issue —— `requirements.txt` 目前取自原构建环境，最小可用集合**没有**验证过。

## 记录方式

通过后把结果写进 `CHANGELOG.md` 的「已验证」小节，注明：

- Windows 版本（如 Win10 22H2）
- Python 版本（从源码跑时）
- WebView2 版本（安装后可在「设置 → 应用」里看到）
- 协议端名称与版本
- 测试日期

## 已知边界

- CI 跑在 `windows-latest` 上，它**自带 WebView2**，只能验证依赖可解与代码可导入，**不能替代真机验证**。
- 绘图（ComfyUI）与语音（VoiceStudio）需要额外下载 GB 级模型，不在本清单范围。
- 本清单不覆盖多轮上下文、图片理解、长回复切分等行为验证，那些见 README 的「尚未验证的场景」。
